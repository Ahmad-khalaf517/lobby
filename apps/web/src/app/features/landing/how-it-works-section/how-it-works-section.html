How it works

From invitation to conversation in moments.

Lobby supports permanent communities and temporary collaboration through one simple flow.

01

Create or choose a space

Members create a server or select an existing one, then open the channel where the conversation belongs.

02

Invite the right people

Add registered members to the server or create a focused guest invitation for external participants.

03

Communicate with context

Everyone arrives in the correct room, sees the relevant discussion, and contributes in real time.
