Frequently asked questions

Clear answers before you enter the room.

Lobby is designed to keep communication simple for both permanent members and temporary guests.

Do guests need to create an account? +

No. A guest opens a valid invitation, chooses a temporary display name, and enters the invited room directly.

Can a guest see the entire server? +

No. Guest access is limited to the channel associated with the invitation.

Can authenticated users join guest-enabled channels? +

Yes. Registered members can participate normally while invited guests enter through the temporary guest flow.

Is Lobby only for work teams? +

No. It can support project teams, communities, study groups, client collaboration, interviews, and other organized conversations.

Can I use Lobby without Docker? +

Yes. Docker is an optional development workflow; the Angular and NestJS applications can still run with the repository's normal local commands.
